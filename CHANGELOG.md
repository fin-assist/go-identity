# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии и выпуск — [docs/releasing.md](docs/releasing.md). Каждый PR, который меняет API или поведение библиотеки, добавляет строку в «Unreleased»; при выпуске раздел получает номер версии и дату.

## [Unreleased]

### Добавлено

- FIN-243: независимые unit/integration/consumer API пороги statements 80% с закреплённым go-test-coverage, проверкой непустого исполнения и штатными artifacts вместо изменённых строк; тесты и регламент проверок.

- FIN-119: проверка JWT пользователя и ServiceAccount, ключи и короткие токены стенда с запретом в prod, кэш JWKS с ротацией и ограничением refresh, таблица вызывающих и контекст, unary/stream интерцепторы, HTTP-middleware, маскирование metadata, метрики отказов и инструкция внедрения; unit-, интеграционные и usage-тесты.
- FIN-119, ревью: общий refresh переживает отмену отдельного запроса; JWKS API-сервера получает отдельный ротируемый токен; допуск 5 секунд для iat/nbf без продления exp; негативные usage-тесты чужого вызывающего/user_id и второго сообщения потока, синхронизированный тест параллельного сбоя JWKS.
- FIN-119, повторное ревью: заблаговременное обновление JWKS с минутными повторами до истечения снимка; кэш коротких JWT стенда учитывает фактический округлённый exp, чтобы не возвращать истёкший токен.
- FIN-119, повторное ревью: проверка необходимости refresh каждые 30 секунд при неизменном минутном ограничителе сетевых загрузок; регрессионный тест задержки тика относительно ограничителя.
